# Visual-decisions fixtures

The four SVG files are strict, inert shape fixtures for mark, favicon,
horizontal lockup, and stacked lockup validation. The focused R2 test builds
the complete cross-bound JSON, font, rights, Affinity, run-root, and hostile
fixtures inside the configured `.runtime` temporary root. This avoids shipping
plausible-looking production availability, reputation, rights, or Owner
approval records as static fixtures.
