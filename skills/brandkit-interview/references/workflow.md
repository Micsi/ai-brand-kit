# Interview playbook

Start from the readiness artifact. Classify every source, ask only for missing
brand axes, record provenance per concrete decision and expose conflicts to the
owner. Unresolved normative conflicts, missing ownership and unsupported legal
claims block; open non-normative values remain explicit owner TODOs.
When explicitly started as `$brandkit-interview` with deep discovery, run the
declared `prepare` command. Persist its human-readable progress after every
answer; its canonical counter requires at least two answer turns, even if the
first answer claims every axis. Stay in `grilling` while its frontier is open. Only then invoke
`domain-modeling`; never invoke the reference-only wrapper. Require non-empty
CONTEXT and ADR documents plus sources in the closed internal handoff. Render
the human review in chat and ask for confirmation/corrections. Only explicit
chat approval authorizes internal `confirm` followed immediately by `consume`;
copy decisions, source bytes and document provenance, never recommendations.
Continue the complete native eleven-axis interview for every remaining axis or
as fallback after any discovery failure.
For visual domains, route the non-normative candidate sheet to the owner. Pass
only candidate IDs or open/not-applicable to `prepare-visual-confirmation`;
show its filled review with resolved values. Only a subsequent explicit exact
confirmation authorizes the existing receipt and consume path. Incorporate the
deterministic consumed visual block, never recommendation values.
